# Sudha Gowda — Personal Portfolio

A premium, animated personal portfolio built with **Next.js 16**, **TypeScript**, **Tailwind CSS**, **Framer Motion**, and **Lottie**.

## ✨ Features

- Animated hero section with Lottie female developer character
- Typing animation for professional roles
- Interactive skills grid (6 categories)
- Projects showcase: SignFlow, BuildHer, Debt Sustainability Classifier
- Internship & Education timeline
- Certifications section
- Animated contact form (mailto)
- Fully responsive — desktop, tablet, mobile
- Premium dark theme with purple/lavender accents

## 🚀 Tech Stack

| Layer | Technology |
|-------|-----------|
| Framework | Next.js 16 (App Router) |
| Language | TypeScript |
| Styling | Tailwind CSS 4 |
| Animations | Framer Motion 14 |
| Character | Lottie React |
| Icons | Lucide React |

## 🛠 Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the portfolio.

## 📦 Build

```bash
npm run build
npm run start
```
